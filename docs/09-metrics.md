# KPI·객관적 평가 지표

| 영역 | 지표 | 측정 방법 | 증빙 |
|---|---|---|---|
| 제품 | 핵심 여정 완료율 | 시나리오 성공 수 / 시도 수 | 테스트 기록 |
| 제품 | 요구사항 구현률 | 완료 Must·Should / 전체 | 요구사항 표 |
| 사용성 | 작업 성공률·오류 | 대표 과업 관찰 | 시연 기록 |
| 기술 | build/lint 통과율 | 릴리스 게이트 결과 | CI 또는 로그 |
| 품질 | 테스트 통과율 | 자동·수동 테스트 결과 | 테스트 리포트 |
| 성능 | 로딩·API 응답 | 브라우저 측정 및 API 타이밍 | 측정표 |
| 안정성 | API 실패·AI 성공률 | 호출 결과 분류 | 운영 로그 |
| 보안 | 권한 테스트 통과율 | Rules 시나리오 실행 | 보안 점검표 |
| 운영 | 배포 재현성·문서 최신성 | 체크리스트와 문서 대조 | 릴리스 기록 |
| 관리 | 스프린트 달성률 | 완료 항목 / 계획 항목 | 회고 기록 |

초기에는 측정값을 기준선으로 확보하고, MVP 종료 시 각 지표에 목표값과 실제값을 함께 기록한다. 측정되지 않은 값은 성과로 주장하지 않는다.
