## 성능 지표 증빙 기준

번들 크기 최적화는 `React.lazy` 적용 여부만으로 완료 처리하지 않는다. 적용 전후 `npm run build` 결과에서 초기 로딩 청크와 lazy 청크의 크기를 비교하고, 500kB 초과 경고가 남는 경우 남은 청크의 원인을 기록한다.

캐시 적중률은 현재 개발 모드 패널이 최신 이벤트 1건을 보여주는 수준이므로, 누적 hit rate로 주장하려면 별도 집계가 필요하다. 원시 사용자 로그를 장기 저장하기보다는 릴리스별 측정표에 memory, local, remote, network, stale 이벤트 수를 기록한다.

AI 운영 지표는 기존 `users/{uid}/aiTripPlans/{planId}/tour_api_verification`의 검증 통계와 Gemini 호출 telemetry를 구분한다. `tour_api_verification`은 장소 검증 결과의 증빙이며, AI 생성 성공률·retry count·latency의 직접 증빙은 별도 기록이 있어야 한다.
