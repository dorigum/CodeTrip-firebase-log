# 핵심 사용자 흐름

## 발견과 저장

1. 사용자가 홈 또는 탐색 화면에 진입한다.
2. 지역·테마·키워드로 목록을 좁힌다.
3. 상세 화면에서 설명, 이미지, 지도, 날씨를 확인한다.
4. 로그인 후 여행지를 찜하거나 폴더에 저장하고 메모를 남긴다.

## AI 일정 생성

1. 사용자가 지역, 기간, 선호, 후보 여행지를 입력한다.
2. Gemini가 일정 초안을 생성한다.
3. 검증된 여행지와 AI 추천 장소를 구분해 표시한다.
4. 사용자가 내용을 수정·저장하거나 다시 생성한다.
5. 실패 시 기본 안내와 재시도 경로를 제공한다.

## 커뮤니티

1. 사용자가 게시글 목록에서 여행 경험을 탐색한다.
2. 상세에서 댓글·좋아요·여행지 태그를 확인한다.
3. 로그인 사용자가 게시글·댓글을 작성·수정·삭제한다.
4. 관련 활동은 알림과 마이페이지에 반영된다.

## 공통 상태

모든 흐름은 로딩, 성공, 빈 결과, 권한 없음, 외부 API 실패, 재시도 상태를 정의한다.
