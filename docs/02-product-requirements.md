# 제품 요구사항

## 우선순위

| ID | 요구사항 | 우선순위 | 완료 조건 |
|---|---|---|---|
| FR-01 | 지역·테마·키워드로 여행지를 탐색한다 | Must | 목록, 검색, 필터, 빈 결과가 동작 |
| FR-02 | 여행지 상세와 지도·날씨 정보를 확인한다 | Must | 상세·외부 데이터·오류 상태가 표시 |
| FR-03 | 회원가입·로그인·비밀번호 재설정을 제공한다 | Must | 인증 상태에 따라 보호 화면이 제어 |
| FR-04 | 여행지를 찜하고 폴더·메모로 관리한다 | Must | 생성·수정·삭제와 개인별 접근 제어 |
| FR-05 | 선호와 후보지를 바탕으로 AI 일정 초안을 생성한다 | Must | 생성·실패·fallback 상태를 사용자에게 안내 |
| FR-06 | 게시글·댓글·좋아요를 제공한다 | Should | 작성·조회·수정·삭제 권한이 일관됨 |
| FR-07 | 활동 기반 알림과 마이페이지를 제공한다 | Should | 읽음·삭제와 활동 내역 확인 |
| FR-08 | 상용 예약·결제·관리자 기능을 제공한다 | Won't | MVP 범위에서 제외하고 백로그에 보관 |

## 비기능 요구사항

- 사용자 소유 데이터는 본인만 읽고 쓸 수 있어야 합니다.
- 커뮤니티 게시글·댓글은 공개 읽기 범위와 작성자별 수정·삭제 권한을 별도로 정의합니다.
- 외부 API 실패 시 전체 화면이 중단되지 않고 재시도 또는 대체 안내를 제공합니다.
- 주요 화면은 데스크톱·모바일 레이아웃에서 사용 가능해야 합니다.
- 모든 배포는 `npm run lint`, `npm run build`, 수동 핵심 시나리오를 통과해야 합니다.
