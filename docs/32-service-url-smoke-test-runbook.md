# 공모전 서비스 URL Smoke Test 실행표

이 문서는 CodeTrip의 공모전 제출 URL이 심사자가 실제로 접속 가능한 상태인지 제출 직전에 확인하기 위한 실행표입니다. `docs/21-service-url-verification.md`가 URL 검증 기준을 정의한다면, 이 문서는 브라우저에서 순서대로 열어 보며 통과·실패를 기록하는 실행 문서입니다.

## 제출 후보 URL

| 항목 | 값 |
|---|---|
| 제출 후보 URL | `https://dorigum-codetrip.web.app` |
| Firebase 프로젝트 | `newagent-9c2a8` |
| Hosting target | `codetrip` |
| Hosting site | `dorigum-codetrip` |
| 검증 기준 문서 | `docs/21-service-url-verification.md` |
| 기준 커밋 기록 | `docs/27-final-validation-execution-sheet.md`의 `기준 커밋` |
| 배포 커밋 기록 | `docs/27-final-validation-execution-sheet.md`의 `배포 커밋`과 `배포 식별자` |

## 사용 시점

- 최종 기능설명서 PDF를 제출 페이지에 첨부하기 전
- Firebase Hosting에 최신 빌드를 배포한 직후
- 테스트 계정 정보를 제출 페이지에 입력하기 전
- 제출 마감 전 마지막으로 서비스 URL을 확인할 때

## 실패 유형 분류

| 실패 유형 | 예시 | 심사 영향 | 우선 조치 |
|---|---|---|---|
| 접속 실패 | DNS 오류, Hosting 404, 빈 화면 | 매우 큼 | 배포 상태와 Firebase Hosting 설정 확인 |
| 라우팅 실패 | 직접 경로 새로고침 404 | 큼 | SPA rewrite 설정 확인 |
| 공개 화면 API 실패 | 여행지·축제 목록 로딩 실패 | 중간~큼 | TourAPI 키, 캐시 fallback, 오류 UI 확인 |
| 로그인 실패 | 테스트 계정 로그인 불가 | 매우 큼 | 테스트 계정 재생성 또는 Firebase Auth 확인 |
| 보호 화면 실패 | 비로그인 접근 시 빈 화면 | 큼 | 라우트 가드와 오류 UI 확인 |
| AI 화면 실패 | Gemini 오류, 무한 로딩 | 중간~큼 | 시연 전 사용량 제한, fallback 안내, 하네스 정책 확인 |
| 개인정보 노출 | 이메일, 키, 콘솔 화면 노출 | 큼 | 캡처 폐기 및 화면 교체 |

## 판정 기준

| 판정 | 조건 |
|---|---|
| 통과 | 공개 URL, 직접 경로 새로고침, 로그인 후 핵심 기능, 로그아웃 후 재로그인이 모두 정상입니다. |
| 부분 통과 | 공개 URL과 직접 경로는 정상이나 테스트 계정 또는 로그인 후 기능 검증이 미완료입니다. |
| 실패 | 제출 URL 접속, 직접 경로, 로그인, 핵심 기능 중 하나가 심사자가 확인할 수 없는 수준으로 실패합니다. |

## 기록 방법

실행 결과는 아래 위치에 남깁니다.

1. `docs/27-final-validation-execution-sheet.md`
   - URL-P01~URL-P06은 기존 URL-01~URL-06에 요약 반영합니다.
   - URL-R01~URL-R05는 기존 URL-07 직접 경로 새로고침 항목에 요약 반영합니다.
   - URL-A01~URL-A06은 TA-01~TA-06에 요약 반영합니다.
2. `docs/13-validation-report.md`
   - 기준 커밋, 배포 커밋, 배포 식별자 또는 배포 시각, 브라우저·OS, 확인 흐름, 실패 지점, 최종 판정을 기록합니다.
3. `docs/17-submission-artifact-manifest.md`
   - smoke test 중 확보한 최종 캡처 파일명과 크기를 기록합니다.
4. `docs/28-submission-readiness-dashboard.md`
   - B-02, B-05, B-09 상태를 갱신합니다.

## 현재 상태

현재 문서 기준으로 공개 URL 후보와 검증 절차는 준비되어 있으나, 최종 제출 직전 smoke test는 아직 실행되지 않았습니다. 테스트 전용 계정 생성, 로그인 후 AI·마이페이지·커뮤니티 화면 확인, 최종 캡처 확보가 완료되어야 `통과`로 판정할 수 있습니다.
