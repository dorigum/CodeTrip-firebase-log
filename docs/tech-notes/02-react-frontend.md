# React 프론트엔드

## 핵심 주제

- 페이지와 재사용 컴포넌트의 경계
- props, local state, effect의 역할
- React Router 기반 화면 전환
- Zustand를 이용한 전역 상태
- 서버 데이터와 UI 상태의 분리
- 로딩·빈 상태·오류 상태·접근성

## CodeTrip 적용 위치

`src/pages`는 화면 단위, `src/components`는 재사용 UI, `src/store`는 전역 상태, `src/api`는 외부 데이터 연계를 담당한다. 새로운 기능은 화면·상태·API·문서의 책임을 분리해서 추가한다.
