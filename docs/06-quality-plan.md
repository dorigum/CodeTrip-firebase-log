# 품질 계획

## 배포 게이트

1. `npm run lint`
2. `npm run build`
3. 핵심 사용자 흐름 수동 검증
4. Firebase Rules 권한 검증
5. 모바일·데스크톱 반응형 확인
6. 변경 문서와 릴리스 기록 확인

## 핵심 시나리오

- 비로그인 탐색·검색·상세 조회
- 회원가입·로그인·로그아웃
- 찜·폴더·메모 생성과 삭제
- AI 일정 정상 생성·빈 입력·실패·재시도
- 게시글·댓글 작성·수정·삭제·좋아요
- 다른 사용자의 데이터 접근 거부
- 공공 API 장애·빈 결과·캐시 만료
- AI timeout
- AI HTTP 429(rate limit)
- AI 잘못된 JSON 응답
- AI 재생성 한도 초과

## 측정

초기 로딩 시간, 주요 API 응답 시간, 캐시 적중률, 오류율, AI 생성 성공률을 릴리스별 기록한다. 자동 테스트 도입 시 핵심 API/상태 로직부터 시작하고, 브라우저 E2E는 대표 흐름에 한정한다. AI 배포 게이트는 정상 생성뿐 아니라 timeout, HTTP 429, 잘못된 JSON, 재생성 한도 초과의 사용자 안내와 로그 결과까지 확인한다.
