# 프로젝트 헌장

## 프로젝트 정의

CodeTrip은 여행자가 지역·테마·검색 조건으로 여행지를 발견하고, 상세 정보를 검토한 뒤 저장·계획·커뮤니티 활동으로 이어지도록 돕는 웹 서비스입니다.

## 문제와 가치

여행 정보는 여러 공공 API와 서비스에 흩어져 있고, 사용자는 탐색 결과를 실제 일정으로 정리하는 데 추가 노력을 들입니다. CodeTrip은 공공 여행 정보, 개인화된 저장 공간, Gemini 기반 일정 초안을 한 흐름으로 제공합니다.

## 목표 사용자

- 국내 여행지를 탐색하고 싶은 사용자
- 관심 여행지를 저장하고 폴더·메모로 계획을 정리하려는 사용자
- 지역·테마·선호 조건을 반영한 일정 초안이 필요한 사용자
- 여행 경험과 정보를 커뮤니티에서 공유하려는 사용자

## MVP 목표

심사자가 핵심 여정을 직접 시연할 수 있는 상태를 6~8주 목표로 합니다.

`탐색 → 상세 확인 → 로그인 → 찜/폴더 저장 → AI 일정 생성 → 커뮤니티 공유` 흐름이 대표 시나리오입니다.

## 범위

포함: 여행지·축제 탐색, 검색·필터, 상세 정보, 인증, 찜·폴더·메모, AI 일정 생성, 게시글·댓글·좋아요, 알림, Firebase Hosting 배포.

제외: 결제·예약, 실시간 교통 최적화, 운영자 관리자 콘솔, 다국가 서비스, 상용 SLA와 대규모 트래픽 최적화.

## 성공 기준

- 대표 시나리오를 오류 없이 시연합니다.
- 핵심 기능의 구현 범위와 미완료 항목을 추적 가능하게 합니다.
- 보안 규칙·배포 절차·품질 검증 결과를 증빙합니다.
- 심사자가 문제, 차별성, 기술 선택, 한계를 문서만으로 이해할 수 있습니다.

## 운영 방식

경량 애자일을 적용합니다. 1~2주 스프린트마다 목표·완료 조건·회고를 기록하고, 요구사항·아키텍처·보안 기준은 변경 시 의사결정 로그를 남깁니다. 최종 승인자는 프로젝트 오너이며, 구현자는 기능·품질·문서의 완료를 함께 책임집니다.
