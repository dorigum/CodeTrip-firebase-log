# AI 플래너 입력·판단 규칙

## 입력 계약

- 일정: 지역, 날짜, 여행 일수, 시작·종료 시간. 종료 시간은 시작 시간보다 늦어야 하며, 같거나 이르면 코스를 생성하지 않습니다.
- 동행: 동행 관계, 인원. 혼자는 1명으로 고정하고, 연인·가족·친구는 본인을 포함해 최소 2명으로 제한합니다.
- 비용: 예산 수준과 1일 총예산 범위
- 이동: 이동 강도와 이동수단(대중교통·자차·도보)
- 취향: 여행 스타일, 우선순위(예산·휴식·맛집·체험·사진·문화), 피하고 싶은 조건
- 상황: 날씨 키워드와 관광공사/위시리스트 후보 장소

## 판단 규칙

1. 비·폭염·한파에는 실내 비중을 높이고 대체 장소를 포함합니다.
2. 저예산은 무료·저가 장소와 비용 효율적인 식사·카페를 우선합니다.
3. 아이·부모님 동반은 이동 거리와 방문 수를 줄이고 휴식 구간을 둡니다.
4. 대중교통은 환승·장거리 이동을 줄이고, 자차는 주차와 접근성을 고려하며, 도보는 인접 권역에 집중합니다. 저장 체크리스트도 대중교통은 환승·배차, 자차는 주차·도로 혼잡, 도보는 거리·경사 안내로 구분합니다.
5. 우선순위는 순위를 매기지 않는 다중 선택 조건입니다. 선택한 모든 항목을 동등하게 고려하되, 다른 조건과 충돌하면 장소 선정과 일정 배치에 우선 반영합니다.
6. 동행 유형은 제목부터 장소별 추천 이유까지 일관되게 적용합니다. 특히 혼자 여행은 친구·연인·가족 동행 표현이 섞이지 않게 합니다.

다음 단계에서는 이 판단 결과를 조건 요약과 장소별 추천 근거로 결과 화면에 표시합니다.
