- [2026-09-06](project-log/2026-09-06.md): CodeRabbit 피드백에 따라 댓글 인덱스가 원본 댓글의 작성자·게시글·여행지 참조와 일치하는지 Rules로 검증하고, 목록·마이페이지가 선택된 콘텐츠의 좋아요만 병렬 조회하도록 보완했습니다. 축제 상세 소개는 운영 시간·장소·참여 방법 중심의 문단으로 나누고 본문의 URL을 클릭 가능한 링크로 표시했으며, 정보 카드 공백·소개 중복 문제를 보정했습니다. 공식 홈페이지와 SNS 외부 링크는 독립된 줄과 아이콘으로 표시하고 한글 도메인·HTML 앵커·평문 URL을 함께 분리했으며, 유효 URL 원문 경로도 유지합니다. 운영 시간의 `※` 안내·계절·요일·월별 구간을 줄바꿈했고, 여행지·행사 목록에는 5페이지 단위 이동을 추가했습니다. 여행지 카드는 행사 카드와 같은 `EXPLORE →` 패턴 및 반응형 페이지 수로 통일했으며, 게시판 최신순은 `created_at` 인덱스·커서 페이지네이션·목록 전용 요약 데이터로 전체 목록과 상세 본문 다운로드를 피하도록 개선했습니다. CodeRabbit PR #32 리뷰 피드백에 따라 게시글 요약 경로를 기본 RTDB 인스턴스 전용 Database Trigger가 단독 동기화하도록 전환하고, 수정 시각 타입 방어·RTDB Trigger 리전 일치, 조회수 atomic increment, 페이지별 댓글 수 병렬 조회, 백필 스크립트 안전성 보강을 완료했습니다. Hosting 배포 전 빌드가 필요하다는 운영 절차와 Trigger 기반 게시글 생성·수정·삭제 점검 결과를 기록했고, 게시글 삭제는 브라우저 경고창 대신 중복 요청을 방지하는 서비스 확인 모달로 통일했습니다. 기능·수정·문제 해결과 검증 결과를 커밋 전 작업 로그에 남기는 규칙도 명확히 했습니다.

## ✍🏻 작성 기준

1. 구현 및 수정 내역은 작업 날짜에 맞춰 `project-log/` 하위 파일에 기록합니다.
2. 장애 오류 분석과 트러블슈팅 이력은 해당 일자 로그에 작성 후 `TROUBLESHOOTING.md`에 링크를 연결합니다.
3. 실행 및 배포 가이드라인이 수정될 시 `guides/` 하위 문서를 최신으로 유지합니다.
4. 커밋 생성 전에는 날짜별 작업 로그와 필요한 트러블슈팅 색인 갱신을 먼저 완료합니다.
