# 2026-09-15 작업 기록

## AI 여행 플래너 개인화 조건 확장

- 가족 동행에 부모님·자녀 동반, 형제·자매, 친척·혼합 세부 유형을 추가했다. 세부 유형을 지정하지 않거나 형제·자매 등을 선택하면 AI가 부모님 동반으로 추정하지 않고 일반 가족 일행 기준으로 코스를 생성한다.
- 대표 지역과 별도로 반드시 방문할 권역을 최대 4개까지 입력하고, 여행 일자별로 특정 권역을 우선 배정하거나 AI 자동 배분을 선택할 수 있게 했다.
- 세부 동행 유형·필수 권역·일자별 권역 배정은 Gemini 프롬프트와 저장된 재생성 맥락에 함께 전달되며, 결과의 조건 배지에도 표시된다.
- 서버는 권역 입력을 다시 정제하고, 가족 세부 유형이 부모님·자녀 동반이 아닐 때 생성 결과의 부모님 표현을 일반 가족 일행 표현으로 보정한다.

## CodeRabbit 권역 입력 정합성 보완

- 필수 방문 권역 입력과 클라이언트 정규화에 서버와 동일한 항목당 40자 제한을 적용해, 긴 권역명이 서버에서 잘린 뒤 일차별 배정값과 달라질 수 있던 문제를 방지했다.

## CodeRabbit 결과 조건 배지 key 보완

- 결과의 `Why this course` 배지에 방문 권역과 우선순위가 같은 문구로 포함돼도 중복 React key가 생기지 않도록 항목 순서를 key에 포함했다.

## AI 플래너 날씨 입력 안내 보강

- 날씨 입력에 예상 날씨 또는 선호 조건을 직접 넣는 방식임을 안내하고, 비·맑음·더움·추움·실내 위주 예시를 추가했다.

## 운영 점검 후 AI 권역·홈 대시보드·폴더 관리 보완

- 조건 기반 AI 플래너에서 필수 방문 권역을 입력하면 각 권역으로 TourAPI 후보를 별도 조회하고, 주소·명칭이 입력 권역과 일치하는 후보만 Gemini에 전달하도록 보완했다. 서버 프롬프트에도 필수 권역 밖 장소를 추천하지 않는 주소 규칙을 명시했다.
- 회원 홈 미니 캘린더의 일정 링크는 폴더 ID와 AI 코스 ID를 함께 전달해, 선택한 위시리스트 폴더와 해당 코스 상세를 바로 열도록 연결했다.
- 홈의 저장 폴더 카드는 화면 폭과 무관하게 가로 스크롤할 수 있도록 하고, 좌·우 이동 버튼으로 더 많은 폴더를 확인할 수 있게 했다.
- 여행 폴더 삭제는 브라우저 경고창 대신 공통 서비스 확인 모달을 사용하도록 바꾸고, 삭제 중 중복 요청을 막으며 삭제 결과를 토스트로 안내한다.
