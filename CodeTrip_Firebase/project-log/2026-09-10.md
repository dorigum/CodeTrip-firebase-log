- 최초 확인은 저장 대상 폴더가 재생성 입력으로 전달되어 폴더 기반 모드가 강제되는 경로를 놓쳤으므로, 검증 완료 상태를 취소했다.

- AI 플래너는 작은 폭에서 지역·기간·동행·시간 입력을 한 줄씩 표시하고, 미생성 코스 미리보기의 최소 높이와 결과 카드 여백을 줄였다. 넓은 모바일 및 데스크톱에서는 다열 입력 구성을 유지한다.

## 메인 히어로 모바일 정보 노출 보정

- 로그인 회원 메인의 위치·날씨 카드는 모바일 히어로 내부 우측 하단에 절대 배치해, 콘텐츠 높이에 밀려 카드 하단이 잘리지 않도록 했다.
- 비회원 메인의 데스크톱 코드 설정 창은 모바일에서 전체 패널을 복제하지 않고, 핵심 데이터 출처를 보여주는 축약 `trip.config.js` 미리보기로 노출해 서비스 성격을 유지하면서 세로 길이를 최소화했다.

## 비회원 메인 카드 그리드 보정

- 서비스 기능 카드 4개는 모바일에서 2×2 그리드로, 이용 흐름 카드 3개는 한 줄 3열로 배치했다.
- 작은 화면에서는 카드별 장식 코드 블록을 숨기고 제목·설명·진입 정보만 남겨, 카드 수를 가로로 늘리면서도 읽기 어려운 과밀 상태를 피했다. 넓은 화면의 상세 카드 정보와 화살표 흐름은 유지한다.
