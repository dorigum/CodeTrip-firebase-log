# 2026-09-10 작업 기록

## AI 플래너 저장 조건 재생성 수동 검증

- 최초 확인은 저장 대상 폴더가 재생성 입력으로 전달되어 폴더 기반 모드가 강제되는 경로를 놓쳤으므로, 검증 완료 상태를 취소했다.
- 재생성은 저장 대상 폴더가 아닌 생성 컨텍스트의 원래 모드·폴더만 사용하도록 보완한다. 조건 기반으로 만들었던 코스는 입력 조건만 복원해, 조건 변경 뒤에는 기존 방문지 후보가 아닌 새 지역 후보로 다시 생성돼야 한다.
- 혼자 여행 조건인데 제목에 친구 여행이 표시된 AI 응답 사례도 확인해, 동행 조건 프롬프트를 보강하고 혼자 여행의 친구 동행 표현을 서버에서 정규화한다.
- 관련 회귀 문제의 원인·수정 방법·확인 기준은 `TROUBLESHOOTING.md` 77번 항목에 기록한다.

## AI 플래너 동행·인원 조건 정합성

- 여행 우선순위는 번호를 매기지 않는 다중 선택 조건임을 입력·판단 규칙 문서에 명확히 기록했다.
- 연인·가족·친구 여행에서 1명으로 생성될 수 있던 문제를 수정했다. 화면의 입력 최소값, 생성 직전 검증, Callable Function 입력 정규화가 모두 최소 2명을 적용한다.
- 혼자는 1명 고정을 유지하며, 동행 유형을 바꿀 때 기존 인원이 조건과 맞지 않으면 자동 보정하고 안내 메시지를 표시한다.

## AI 플래너 일정 시간 범위 검증

- 종료 시간이 시작 시간보다 이른 경우에도 코스가 생성되고, 모델이 종료 시간을 무시한 채 시작 시간부터 일정을 구성하던 문제를 확인했다.
- 종료 시간이 시작 시간보다 늦은지 화면 생성 전과 Callable Function에서 모두 검증한다. 잘못된 범위는 화면에 오류를 표시하고, 서버는 `invalid-argument`로 거절한다.
