# 2026-09-17 작업 기록

## 외부 서비스 fallback·Gemini 오류 안내 검증

- Open-Meteo 날씨와 Nominatim 위치명 조회 실패 시 기본 여행 날씨·서울 위치로 안전하게 fallback하는 생성 함수를 분리했다.
- Gemini Callable 오류는 인증 만료, 요청 과다, 응답 지연, 서버 불안정 상태별 사용자 안내 문구로 정규화했다.
- 외부 서비스 fallback·Gemini 오류 테스트를 CI 유틸리티 테스트에 포함했고, 로컬 테스트·린트·빌드를 통과했다.

## TourAPI 실패 응답 스모크 검증

- TourAPI가 성공 코드 대신 오류 코드를 반환할 때 신규 여행지 업데이트로 저장하지 않고, 서버 경고 로그와 예외로 차단하는 회귀 테스트를 추가했다.
- Functions 테스트는 19건 전체 통과했다.

## E2E 스모크 테스트와 운영 기록 정리

- Playwright 기반 공개 로그인 경로, 비로그인 보호 경로, 로그인 화면 복귀 E2E 스모크 테스트 3건을 추가하고 CI의 빌드 뒤 단계에 포함했다.
- 라우트 지연 로딩의 모바일 5G 수동 관찰 결과를 캐시 측정표에 기록했다. 반복 접속에서 빈 결과·요청 실패는 재현되지 않았으며, 정량 LCP와 캐시 이벤트 값은 미측정으로 구분했다.
- 백로그의 코드 스플리팅·번들 기준선 항목과 기술 부채 등록부의 Database Rules 자동화 상태를 실제 완료 증빙에 맞춰 정리했다. React Hook effect 의존성을 보완하고, 데이터 요청·초기화를 취소 가능한 예약 실행으로 전환해 린트 경고 11건도 해소했다.

## 의존성 보안 업데이트와 재검증

- 운영 의존성의 고위험 감사 항목을 줄이기 위해 `axios` 1.20.0, `firebase` 12.19.0, `react-router-dom` 7.18.4로 업데이트했다. Firebase Realtime Database 경로의 `websocket-driver`도 0.7.5로 갱신됐다.
- 개발 도구는 `vite` 8.3.0과 `firebase-tools` 15.30.1로 올리고, 비파괴 `npm audit fix`로 잠금 파일의 하위 패키지 패치를 반영했다.
- `npm audit --omit=dev` 결과 운영 의존성 취약점 0건을 확인했다. 전체 감사에 남은 7건은 Firebase CLI 하위 의존성의 moderate 항목이며, 해결을 위해 Firebase CLI를 과거 10.1.1로 내리는 파괴적 변경이 필요해 보류한다.
- `npm run lint`(기존 경고 11건), `npm run build`, 유틸리티 테스트, Functions 테스트(18건), Database Rules Emulator 테스트(15건)를 모두 통과했다.

## AI 폴더 선택 수·위시리스트 페이지네이션 보정

- 폴더 기반 AI 플래너의 `선택 수 / 폴더 장소 수` 표시는 현재 폴더 안에서 선택된 장소만 분자로 계산하도록 수정했다. 다른 폴더에서 남은 선택 ID 때문에 `4 / 3`, `2 / 1`처럼 불가능한 값이 보이던 문제를 제거했다.
- 데스크톱 위시리스트는 2열·4열 카드 구성에 맞춰 페이지당 8개를 표시해 마지막 행의 빈 카드 칸을 없앴다.
- 위시리스트 페이지 전환에서 카드 영역을 화면 최상단으로 자동 스크롤하던 동작을 제거해, 누른 페이지 버튼과 현재 위시리스트 위치를 유지한다.

## 회원 메인 추천 카드 경계 보정

- 회원 메인의 현 위치·관심 지역·축제 추천 카드에서 기본 큰 그림자를 제거하고, 마우스를 올렸을 때만 가벼운 그림자를 적용했다. 카드 하단에 불필요한 경계처럼 보이던 그림자 겹침을 줄였다.

## 회원 메인 폴더 목록 반응형 보정

- 데스크톱 회원 메인의 저장 폴더 목록을 가로 스크롤 대신 3열, 넓은 화면에서는 4열의 여러 행 그리드로 표시하도록 변경했다.
- 폴더 이동 화살표는 모바일 가로 스와이프 화면에서만 노출해, 데스크톱의 남는 여백과 불필요한 이동 동작을 제거했다.

## 회원 탈퇴와 개인 데이터 정리

- 계정 설정에 복구 불가 안내와 본인 확인 절차를 포함한 회원 탈퇴 모달을 추가했다. 이메일 계정은 현재 비밀번호, Google 계정은 Google 재인증 팝업을 사용한다.

## 라우트 단위 코드 스플리팅

- 첫 진입 JavaScript 묶음이 커지는 문제를 줄이기 위해 모든 페이지를 `React.lazy`로 분리하고 `Suspense` 로딩 UI를 추가했다.
- 공통 레이아웃·인증 가드만 초기 번들에 남기고, 홈·탐색·AI 플래너·마이페이지 등은 해당 경로에 진입할 때 내려받도록 변경했다.
- CI의 Fast Refresh 린트 규칙에 맞춰 지연 로딩 페이지 선언과 로딩 컴포넌트를 `main.jsx` 밖 모듈로 분리했다.
