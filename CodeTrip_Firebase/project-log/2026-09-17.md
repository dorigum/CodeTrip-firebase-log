# 2026-09-17 작업 기록

## AI 폴더 선택 수·위시리스트 페이지네이션 보정

- 폴더 기반 AI 플래너의 `선택 수 / 폴더 장소 수` 표시는 현재 폴더 안에서 선택된 장소만 분자로 계산하도록 수정했다. 다른 폴더에서 남은 선택 ID 때문에 `4 / 3`, `2 / 1`처럼 불가능한 값이 보이던 문제를 제거했다.
- 데스크톱 위시리스트는 2열·4열 카드 구성에 맞춰 페이지당 8개를 표시해 마지막 행의 빈 카드 칸을 없앴다.
- 위시리스트 페이지 전환에서 카드 영역을 화면 최상단으로 자동 스크롤하던 동작을 제거해, 누른 페이지 버튼과 현재 위시리스트 위치를 유지한다.

## 회원 메인 추천 카드 경계 보정

- 회원 메인의 현 위치·관심 지역·축제 추천 카드에서 기본 큰 그림자를 제거하고, 마우스를 올렸을 때만 가벼운 그림자를 적용했다. 카드 하단에 불필요한 경계처럼 보이던 그림자 겹침을 줄였다.

## 회원 메인 폴더 목록 반응형 보정

- 데스크톱 회원 메인의 저장 폴더 목록을 가로 스크롤 대신 3열, 넓은 화면에서는 4열의 여러 행 그리드로 표시하도록 변경했다.
- 폴더 이동 화살표는 모바일 가로 스와이프 화면에서만 노출해, 데스크톱의 남는 여백과 불필요한 이동 동작을 제거했다.

- 계정 설정에 복구 불가 안내와 본인 확인 절차를 포함한 회원 탈퇴 모달을 추가했다. 이메일 계정은 현재 비밀번호, Google 계정은 Google 재인증 팝업을 사용한다.
