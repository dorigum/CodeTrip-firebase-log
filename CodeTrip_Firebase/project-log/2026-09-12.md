- 데이터 보안 경계, 서버리스 자동화, 운영 안정성, 현재 구현 범위와 향후 고도화 과제를 구분해 명시했다.

## 일반 회원가입 인증 상태 경합 보완

- 일반 회원가입 중에는 인증 상태 감시기가 신규 Firebase Auth 사용자를 세션 만료로 판단해 로그아웃하지 않도록 회원가입 전용 진행 상태를 추가했다.
- 신규 계정의 RTDB 프로필 저장은 인증 토큰을 강제 갱신하고 권한 거부 시 재시도하도록 보완했다.
- 가입 완료 후에는 명시적으로 로그아웃해 기존의 “가입 후 로그인 화면으로 이동” 흐름을 유지한다.
