# 2026-09-12 작업 기록

## 공모전 심사용 기술 아키텍처 문서 보강

- `docs/04-architecture.md`를 심사자가 빠르게 이해할 수 있는 서비스 문제·사용자 흐름 중심 구성으로 확장했다.
- 탐색·저장·AI 일정·관심 지역 알림의 비즈니스 흐름과 React·Firebase·외부 API의 시스템 구조를 Mermaid 다이어그램으로 정리했다.
- 데이터 보안 경계, 서버리스 자동화, 운영 안정성, 현재 구현 범위와 향후 고도화 과제를 구분해 명시했다.

## 일반 회원가입 인증 상태 경합 보완

- 일반 회원가입 중에는 인증 상태 감시기가 신규 Firebase Auth 사용자를 세션 만료로 판단해 로그아웃하지 않도록 회원가입 전용 진행 상태를 추가했다.
- 신규 계정의 RTDB 프로필 저장은 인증 토큰을 강제 갱신하고 권한 거부 시 재시도하도록 보완했다.
- 가입 완료 후에는 명시적으로 로그아웃해 기존의 “가입 후 로그인 화면으로 이동” 흐름을 유지한다.

## 비로그인 Header 회원가입 진입 추가

- 비로그인 Header에 기존 `Sign In`과 함께 `Sign Up` 버튼을 추가해 회원가입 화면으로 바로 이동할 수 있게 했다.
- 좁은 화면에서는 회원가입 버튼의 텍스트를 숨기고 아이콘만 남겨 검색 영역과 인증 제어가 겹치지 않게 했다.

## 회원 메인 추천 카드 데스크톱 그리드 보정

- 회원 메인 하단 추천 카드 영역을 사이드바가 표시되는 데스크톱 폭부터 3열 그리드로 전환해, 일부 카드가 잘린 채 이동하지 못하던 문제를 해소했다.
- 모바일 폭에서는 기존의 가로 스와이프·스냅 동작을 유지해 좁은 화면에서 카드 내용을 순서대로 확인할 수 있다.

## 회원 메인 추천 기준·설명 가독성 보정

- 첫 번째 추천 카드를 `현 위치 기반 추천`으로 표기해, 두 번째 `관심 지역 기반` 맞춤 추천과 기준을 명확히 구분했다.
- 데스크톱의 관심 지역 기반 추천 카드에서는 안내 문구를 최대 두 줄로 표시해 긴 설명이 말줄임으로 잘리지 않게 했다.
