# 2026-09-18 개발 기록

## 프로젝트 문서 색인 정리

- 날짜별 프로젝트 로그의 중복 항목을 제거하고, 최신 CI 통과 이력을 날짜별 색인에 통합했다.
- 트러블슈팅 색인에는 폴더 기반 AI 지역·조건 무결성, 체크리스트 중복, CI E2E 복구 사례를 추가했다.
- 검증 보고서·백로그는 PR #39 Quality checks 통과와 현재 심사 제출 준비 상태를 반영해, 완료된 과거 PR 작업이 현재 작업판에 남지 않도록 정리했다.

## CI E2E 미리보기 서버 포트 고정

- PR #39의 `Quality checks` 실패 로그를 확인해, CI에서 `vite preview`가 기본 포트 `4173`으로 실행되는 동안 Playwright가 `5173`을 기다려 120초 후 시간 초과한 것을 확인했다.
- CI용 미리보기 명령에 `--port 5173`을 명시해 Playwright의 `baseURL`·대기 URL과 서버 포트를 일치시켰다.
- 동일한 `CI=true` 조건에서 E2E 라우팅 스모크 테스트를 다시 실행했다. 이 과정에서 화면의 시각 라벨을 접근성 레이블로 가정한 테스트가 실제 입력 요소를 찾지 못한 것을 확인해, 로그인 폼은 `email`·`password` input 타입을 기준으로 확인하도록 보완했다.
- 후속 실행에서 GitHub Actions에 Firebase 공개 설정이 없어 초기화 단계에서 화면이 렌더링되지 않는 것을 재현했다. 공개 라우팅 E2E에는 실제 운영 프로젝트를 연결하지 않고, 초기화에 필요한 형식상 유효한 CI 전용 더미 설정을 워크플로 환경 변수로 주입했다.

## 게시글 댓글 알림 미리보기

- 다른 사용자가 게시글에 댓글을 남기면 게시글 작성자 알림에 작성자명과 댓글 본문 일부를 함께 저장하도록 보완했다.
- 공백·줄바꿈은 한 줄로 정리하고, 80자를 초과하는 댓글은 말줄임표를 붙여 전체 본문이 알림 목록에 노출되지 않게 했다.
- 기존 알림은 저장 시점에 댓글 원문이 없으므로 유지하며, 새 댓글부터 미리보기 문구가 적용된다.
- `npm --prefix functions test` 20건, `npm run lint`, `npm run build`를 통과했다.

## 공모전 기능설명서 API 설명 보강

- 5페이지 제출 후보의 OpenAPI·기타 API 영역을 단순 목록 대신 각 데이터가 맡는 화면·기능 중심 설명으로 바꿨다.
- 차별성은 탐색·저장·AI·커뮤니티 연결과 TourAPI 검증 구조를 유지했고, 발전계획은 이미 완료된 항목과 실제 사용량 관측·외부 API 장애 기록·지역별 큐레이션의 후속 과제를 구분했다.
- 개정 PPTX/PDF는 5페이지이며, 5번 슬라이드 렌더링으로 문장 잘림이 없는 것을 확인했다.
