# 2026-08-27 작업 로그

## 1. Home 추천 카드 중간 폭 레이아웃 보정

사용자 메인 화면에서 브라우저 폭을 줄였을 때 `지역 기반 추천`, `관심 지역 기반 즉흥 추천`, `축제 및 행사` 카드가 2열과 1열로 어중간하게 줄바꿈되어 카드 균형이 깨지는 문제를 확인했습니다. 특히 데스크톱과 모바일 사이의 중간 폭에서는 카드가 넓게 유지되지 못하고, 축제 카드만 다음 줄로 내려가 화면 오른쪽에 빈 공간이 크게 남았습니다.

### 수정 방향

- 매우 넓은 데스크톱 화면에서는 기존 의도처럼 3개의 추천 카드를 한 줄에 표시합니다.
- 중간 폭과 모바일에 가까운 화면에서는 2열 배치를 사용하지 않고, 1열 3줄 구조로 전환합니다.
- 카드 내부 구조는 유지하되 외부 그리드 기준만 단순화해 카드 높이와 줄바꿈을 예측 가능하게 관리합니다.

### 수정 내용

- `src/pages/Home.jsx`의 Home 추천 카드 그리드에서 중간 폭 `lg:grid-cols-2` 구조를 제거했습니다.
- `xl:grid-cols-3` 이상에서만 3열을 사용하도록 조정했습니다.
- 기존에 첫 번째·두 번째 카드를 감싸던 내부 2열 래퍼를 제거해 세 카드가 동일한 그리드 규칙을 따르도록 정리했습니다.

### 검증 기준

- 중간 폭 화면에서 Home 추천 카드가 2개 + 1개 형태로 깨지지 않아야 합니다.
- `xl` 이상 데스크톱 화면에서는 세 카드가 한 줄에 균등하게 표시되어야 합니다.
- 모바일 화면에서는 세 카드가 세로로 자연스럽게 쌓여야 합니다.
