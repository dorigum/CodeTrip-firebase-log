# 2026-09-11 작업 기록

## 회원 메인 대시보드 밀도 보정

- 회원 메인 상단 제목·설명 글자 크기를 모바일 기준으로 낮추고, 제목과 설명 사이 여백을 늘려 답답한 인상을 완화했다.
- 위치 기반 추천·관광지 날씨·인기 테마 카드의 모바일 패딩, 헤더 높이, 이미지 높이를 축소했다.
- 넓은 데스크톱(`xl`) 화면에서는 기존 카드 크기를 유지해 정보량과 시각적 균형을 보존했다.

## 위시리스트 카드 밀도 보정

- 저장 여행지 카드를 가로형 컴팩트 카드로 바꿔 이미지 높이로 인한 세로 스크롤을 줄였다.
- 목록은 작은 화면에서 한 열, 중간 화면부터 두 열, 아주 넓은 화면에서는 세 열로 배치되도록 조정했다.

## PR #39 CodeRabbit 후속 보완

- AI 플랜 캘린더의 날짜 파서는 생성된 날짜의 연·월·일을 원문과 다시 비교해, 2월 31일처럼 JavaScript가 다음 달로 자동 보정하는 잘못된 날짜를 제외한다.
- AI 플래너의 여행 날짜 안내문은 기본 한 열을 사용하고 420px 이상에서만 두 입력 열 전체를 차지하도록 해 좁은 화면의 가로 넘침을 방지했다.
- AI 플랜 삭제 성공 직후 Zustand의 `aiTripPlans`에서도 해당 플랜을 제거해 홈 미니 캘린더에 삭제된 일정이 남지 않게 했다.
