# 2026-08-15 작업 로그

> 이 문서는 2026-08-16에 기존 커밋과 검증 문서를 기준으로 소급 정리했습니다.

## 1. 작업 개요

공모전 제출 준비 브랜치의 CodeRabbit 리뷰를 반영하고, Gemini 공개 시연 보안 게이트와 제출 차단 조건을 강화했습니다. 또한 Google OAuth는 즉시 구현이 아니라 별도 계획 문서로 관리하기로 정리했습니다.

## 2. 주요 작업

- 제출 체크리스트의 범위와 차단 조건을 보강했습니다.
- 지역 특화 서비스 상태를 `아니오` 기준으로 문서 간 동기화했습니다.
- Google OAuth 계획 문서에 기존 이메일 로그인 세션 정책과의 연결 기준을 보강했습니다.
- Gemini 공개 시연 보안 게이트를 추가해, 클라이언트 직접 Gemini 호출 상태에서는 공개 URL의 신규 AI 생성을 제출 통과 기준으로 보지 않도록 했습니다.
- 민감정보 전달 기준을 강화해 테스트 계정 비밀번호, OpenAPI 인증키, Gemini API 키 원문을 저장소·검증 보고서·PR 댓글에 기록하지 않도록 정리했습니다.

## 4. 리뷰 대응

- CodeRabbit 피드백을 반영해 제출 통과 기준과 보안 게이트의 문구를 정리했습니다.
- AI Planner의 비활성화 안내 화면만으로는 기능 통과로 보지 않고, Functions 프록시 기반 생성 성공 또는 보안 게이트 통과 후 저장된 일정 표시만 인정하는 기준을 명시했습니다.

## 5. 남은 작업

- Gemini API 호출을 Firebase Functions Callable Function으로 실제 전환해야 합니다.
- Functions Secret 등록, Functions 배포, Hosting 재배포, 배포 산출물 키 미포함 검증이 필요합니다.
- 기존 노출 가능 Gemini 키 폐기 또는 교체 절차가 필요합니다.
